# Absorb — PRD

## Problem
People learn passively — videos, scattered flashcards, generic courses — and forget most of it. No single tool guides a learner from first exposure to genuine understanding and real-world application.

## Target user
Digitally active students, young professionals, and self-learners aged 16–35 who want to deeply understand and apply new topics, not memorise them.

## Core objects
- **Topic** — a subject the user wants to learn (e.g. "Negotiation basics").
- **Journey** — a personalised, multi-stage path generated for a topic: Learn → Practice → Apply.
- **Lesson** — a bite-sized learning unit within a journey (content text + key concept).
- **PracticeItem** — a graded exercise attached to a lesson: flashcard, multiple-choice, fill-in-the-blank, or short test.
- **Challenge** — a real-world project the user applies their learning to (daily-life scoped).
- **Progress** — per-lesson completion, practice scores, retention metrics, strength/weakess tags.

## MVP (v1) checklist
- [ ] Enter any topic → Absorb generates a full journey (lessons, practice items, real-world challenge).
- [ ] Browse and complete lessons (read + mark understood).
- [ ] Practice with flashcards, MCQs, and fill-in-the-blank; get instant feedback.
- [ ] Take a short end-of-journey test.
- [ ] View a real-world challenge, mark it started/completed.
- [ ] See overall progress: lessons done, practice accuracy, understanding score, journey completion.
- [ ] Works without login (demo-first with seed data).
- [ ] Clean, animated, responsive UI with sidebar navigation.

## Non-goals (v1)
- No live classes, social features, or content marketplace.
- No spaced-repetition scheduler, certification, or payment tiers.
- No classroom management, group learning, or instructor tools.

## Success criteria
A user enters "Basics of Negotiation," Absorb generates a journey with lessons and practice, the user completes at least one lesson, answers practice questions with feedback, reads the real-world challenge, and sees their journey progress updated — all without logging in.
